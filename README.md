## About

Hane Mod Studio develops gameplay scripts and in-game interfaces for FiveM roleplay servers. Every resource is written for the Qbox ecosystem and tested on live servers before release.

## What we build

- Gameplay systems: multicharacter, rentals, minigames, chat
- In-game interfaces: HUD, inventory, loading screens
- Server tools: web panels and Discord integrations

## Stack

| Layer | Tools |
| --- | --- |
| Framework | qbx_core |
| Libraries | ox_lib, ox_inventory, oxmysql |
| Interface | HTML, CSS, JavaScript |
| Database | MySQL / MariaDB |

## Naming

All resources use the `hane_` prefix.
